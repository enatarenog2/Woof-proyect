Woof App
==================================

The Woof app is a list of dog photos with information about them including their name, age, and favorite activity. This app also uses Material Design to create a beautiful app experience for the user.

Introduction
------------

This is the starter code for the Woof app project. This project is an opportunity for you to learn Material3 and reinforce the concepts you've learned so far in Android Basics with Compose.

Pre-requisites
--------------

- Rows/Columns
- Modifiers
- Scaffold
- Adding images
- Button click handlers
- Functions
- Classes
- Lists
- App architecture

Getting Started
---------------

1. Download the project
2. Open the project in Android Studio
3. Run the project

3 lineas
---------------
1. Tarjetas: Utilizaría una tarjeta para cada movimiento financiero, separando visualmente los ingresos y gastos del fondo de la pantalla, con esquinas redondeadas y espacio entre cada elemento.
2. Jerarquía de textos: Mostraría la descripción del movimiento con un tamaño de letra más grande y en negrita, mientras que el monto y la fecha tendrían un tamaño menor para facilitar la lectura.
3. Colores y contraste: Utilizaría un color principal para identificar la aplicación y mantendría un contraste adecuado entre el fondo y el texto para que toda la información sea fácil de leer.
